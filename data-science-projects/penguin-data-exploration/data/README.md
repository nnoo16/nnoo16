Simplified CSV used as distributed. Missing values remain in the raw file. Analyses filter only the required fields; no values are imputed. The data were collected by Kristen Gorman and Palmer Station LTER. Original study: Gorman, Williams & Fraser (2014), https://doi.org/10.1371/journal.pone.0090081.

A Kaggle discovery page for this dataset is https://www.kaggle.com/datasets/parulpandey/palmer-archipelago-antarctica-penguin-data. The bundled bytes come from the original source, not Kaggle. No competition submission or leaderboard score is claimed.
