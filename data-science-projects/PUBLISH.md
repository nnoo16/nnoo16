# Publish these projects

1. Open https://github.com/nnoo16/nnoo16 while signed in as nnoo16.
2. Select the link to upload existing files. If files are already present, use Add file > Upload files.
3. Drag the contents of the GitHub_Upload folder (README.md, .github, and data-science-projects) into the upload page.
4. Review the file list and commit the upload. Preserve all nested folders.

Do not upload the ZIP itself. Each project folder includes its executed notebook and all required data. GitHub may require you to enable the included workflow before it can run. Local notebook checks have already passed; remote workflow success has not been verified.

Official upload instructions: https://docs.github.com/en/repositories/working-with-files/managing-files/adding-a-file-to-a-repository
