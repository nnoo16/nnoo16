Raw whitespace-delimited file retained unchanged. Quoted car names are parsed with shlex. The ? horsepower marker becomes NaN. Median imputation occurs only inside model fits. Origin codes are 1=USA, 2=Europe, 3=Japan. Two-digit model years 70–82 denote 1970–1982. Car names are excluded from features.

A Kaggle discovery page for this dataset is https://www.kaggle.com/datasets/uciml/autompg-dataset. The bundled bytes come from the original source, not Kaggle. No competition submission or leaderboard score is claimed.
