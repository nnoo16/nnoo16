Raw iris.data retained unchanged. In memory, 1-based row 35 petal width is corrected to 0.2 cm; row 38 sepal width and petal length are corrected to 3.6 and 1.4 cm, following the UCI data page. Identical corrected feature-and-label rows are then removed before splitting. Original 0-based row IDs are preserved in output files.

A Kaggle discovery page for this dataset is https://www.kaggle.com/datasets/uciml/iris. The bundled bytes come from the original source, not Kaggle. No competition submission or leaderboard score is claimed.
